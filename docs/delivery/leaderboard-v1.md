# Leaderboard（`/leaderboard`）— 整体交付说明 v1

> 这份文档说的是排行榜这一页。2026-09-22 按 Figma 设计稿整页回流，旧版（紫色霓虹标题 + 星点粒子 + 单列卡片列表 + 浮动紫色「My Ranking」条）已全部删除；2026-09-29 收口：榜单改 Top 30 平铺不分页、分享卡名次带榜别与周期。
> 研发只读这一份就能从旧版做出现在的排行榜。
> 怎么读：先看 §0 知道去哪儿查、§0.1 学会看字典、§0.2 一分钟看懂这页，再按章节读。

## 通俗导读

排行榜一页三件事：**谁在榜上**（前三名站领奖台，第 4–30 名一张表到底，可按 PNL / ROI / Volume 三个榜 × Daily / 7 Days / 30 Days / 180 Days 四个时间范围切换）、**我成绩如何**（表格正下方常驻一条「Your Ranking」）、**把我的名次晒出去**（Your Ranking 上的分享按钮拉起海报：头像 + `#13 · 7D PNL` 胶囊 + 三格数据 + 邀请码二维码，可存图 / 复制链接 / 发 X / Telegram）。页面滚动时右下角还有一条小浮条告诉你「你第几、多少钱」，Your Ranking 一进视野它就退场。

## 0.1 字典怎么看（`/style-guide` 阅读指南）

字典 = 每个模块「全部状态 × 桌面 / 手机」的活体样张：每一态都是**生产组件挂固定数据渲染出来的**，不是截图，可以直接对着抄；旁边的表告诉你这一态什么时候出现。看的顺序：

| 步 | 做什么 | 看到什么 |
|---|---|---|
| 1 | 打开 `https://omenxv2.lovable.app/style-guide`（不用登录） | 左栏是节点树。本次交付只在一个节点里：**Lite** 组的 `Leaderboard ✅` |
| 2 | 点进节点，先看顶部「本页目录」 | 目录 = 这个节点里的小节，按产品页从上到下排：Ⓐ 整页 → Ⓑ 筛选行 → Ⓒ 三甲领奖台 → Ⓓ 榜单表格 / 列表 → Ⓔ ② Your Ranking → Ⓕ ① 浮动定位器 → Ⓖ 分享弹窗与分享卡；每条右侧是该小节的编号范围，点目录条直接滚过去 |
| 3 | 每个小节顶部一行黄框「定位行」 | 写着：这页对应哪个路由；字段 / 文案去 `copy-dictionary.md` 哪一节；口径去哪份交付文档（就是本文） |
| 4 | 小节里每张样张 | 上面一行小字 = **编号 · 状态名（组件名）**，如 `LB-13 · ② Your Ranking · 已排名 · desktop`；样张本体是 iframe 里的真组件（桌面帧 100% 宽、手机帧 375 宽），能 hover、能点、能滚 |
| 5 | 样张下面的表 | 列固定为「状态 / 触发条件 / 视觉 / 数据来源」——**触发条件就是判定表达式**（如 `user.username === currentUsername`），来源列写的是 Figma 节点或规范坐标 |
| 6 | 找某个具体编号 | 页头搜索框直接敲编号（`LB-16` / `LB-20b`）或文字，结果行「编号 · 名 → 节点 › 小节」，点了自动切节点并滚到那张样张 |
| 7 | 只要一张样张单独看 / 截图 | `https://omenxv2.lovable.app/style-guide/preview?c=<key>`；本页的 key 全部是 `leaderboard-` 前缀：`page-guest` `filters` `filters-mobile` `podium-pnl` `podium-pnl-mobile` `podium-roi` `podium-volume` `table` `table-me` `list-mobile` `list-mobile-me` `your-ranking` `your-ranking-mobile` `your-ranking-unranked` `your-ranking-guest` `your-ranking-mobile-guest` `locator` `locator-mobile` `locator-unranked` `locator-guest` `share-modal` `share-drawer` `share-card` `share-card-dimensions` |

编号规则：全部 `LB-` 前缀；无后缀 = 桌面（或双端同一 case），`b` = 同一状态的手机形态（LB-3b / LB-5b / LB-8b / LB-9b / LB-13b / LB-15b / LB-16b / LB-19b），`LB-20b` 例外——是分享卡三个榜并排的变体。LB-2 / 4 / 10 / 11 / 12 / 21 已并入邻近 case 或作废（分页态 LB-11 / LB-12 于 2026-09-29 随分页一起删除），字典节文件头有对照。§5 状态索引只列编号，本节负责教怎么找。

只在字典可见、生产暂时凑不出条件的态（不是 bug）：**已登录但没进 Top 30** 的两态——`LB-14`（Your Ranking · Unranked）与 `LB-17`（浮动定位器 · Unranked）——演示账号 alex_carter 在榜上（#13），要看这两态只能在字典看；分享卡的 ROI 榜 / Volume 榜 / 不同周期版本在生产上要先切筛选再点分享，字典 `LB-20b` 三张并排一次看全。

## 0.2 一分钟看懂

这一页回答三个问题，各自有一件独立的 UI 负责，互不重复：

| 问题 | 谁回答 | 在哪 |
|---|---|---|
| 谁在榜上 | 三甲领奖台 + 榜单表格 | 页面主体 |
| 我成绩如何 | ② Your Ranking | 表格正下方，恒显 |
| 我现在在哪、怎么跳过去 | ① 浮动定位器 | 跟随视口；② 进入视野就淡出 |

分享只有一个出口：② 上的按钮（移动端另有顶栏图标），拉起分享弹窗。海报上的名次带榜别与周期（`#13 · 7D PNL`），取自点分享那一刻筛选行的选择。

## 1. 页面骨架与纵向坐标

桌面以**页面顶端**为 0（= Figma 616:1399 画板顶；顶栏 sticky 浮在头图上、高度由页面实测，不写死），数值已在生产实测核对：

| 区块 | 起 | 止 |
|---|---|---|
| 头图（全宽） | 0 | 384 |
| 筛选行 | 430 | 478 |
| 三甲领奖台（**占版高度**） | 526 | 977 |
| 地面渐变带（全宽 1440×236） | 815 | 1051 |
| 榜单表格 | 1041 | 1707 |
| ② Your Ranking | 1731 | 1819 |

**领奖台是故意向下溢出的**：台阶实际画到 1204，但在版面上只占到 977，中间那 227px 被不透明的表格卡盖住。移动端同理——占版 160、实渲 228.6、溢出 68.6 藏在列表卡后面。**不要按台阶的实渲高度排版**，否则表格下面会空出一大块。台阶内部的纵向节奏（名字行高、底板 → 数值、数值 → 说明三档间距）以 `DESIGN.md` §Addendum 2026-09-22 第 2 条为准，分隔线必须在数值上方留 6–11px，不许穿过数字。

榜单表下方：桌面 Your Ranking 之后到页脚留全站统一的 40；移动端 Your Ranking 之后留 32 再接页脚（页脚容器自己让出底导高度）。

容器：头图走 `DESIGN.md` §5 已登记的「Leaderboard 营销 hero」豁免（全宽）；**头图以下一律 Layout Wide** `mx-auto w-full max-w-7xl px-4 lg:px-6`（内容宽 1232，正好等于设计稿）。

移动端左右边距 16（内容宽 358），区块间距一律 16。

## 2. 模块规格

### 2.1 筛选行
桌面：指标分段器 360×48（底 `#131519`、padding 4、圆角 12；tab 112×40，选中底 `#33D6FF` 字 `#1C1F26`，未选 `#9CA2AB`，字体 Space Grotesk Bold 14/20）+ 右侧 `7 Days` 下拉 90×40 + `Share` 96×40。
移动：分段器满宽（tab 等分 111.33×40）；时间范围**单起一行**（左 `Time range` 12/500 + 右下拉 84×38），**移动端没有 Share 按钮**（入口在顶栏与 ② 卡）。
时间范围四项：`Daily` / `7 Days` / `30 Days` / `180 Days`。

### 2.2 三甲领奖台
三列各 344 宽、间隙 37；1st 最高，2nd 下沉 48，3rd 下沉 64。台阶、奖杯、皇冠都是从 Figma 逐路径取回的**矢量件**，不要用 CSS 近似重画。
奖牌三档：金 `#FFD365`（辅 `#DECFA5`，奖杯墨 `#5F5434`）/ 银 `#CDCDCD`（辅 `#848484`，墨 `#585858`）/ 铜 `#B38A48`（辅 `#6C5227`，墨 `#6C5227`）。
移动端是**独立尺寸表**，不是响应式缩放：头像 37.86、徽章 16×12.76、用户名 10、数值 12、副标 8、台阶 115×129.35。

### 2.3 榜单表格 / 列表
桌面五列：`RANK 56 / TRADER flex / TRADES 160 / PNL (USD) 200 / CHANGE 160`（后三列右对齐），左右内边距 48，表头 51 高、行 56 高、行下描边 1px `#23262D`。
移动两列：表头 40 高（`RANK / TRADER` · 指标名），行 64 高、左右 12、头像 28，右侧两行＝金额 + 名次变化。
名次变化三态：涨 `↑N ranks` + MONEY 绿；平 `—` + `#9CA2AB`；跌 `↓N ranks` + MONEY 红。
当前用户行**只改头像描边**为 `rgba(51,214,255,0.4)`，不做整行底色、不加徽章。

### 2.4 榜单规模：Top 30 平铺，不分页（CPO 2026-09-29 拍板）
榜单固定展示前 30 名：前三进领奖台，第 4–30 名 27 行一张表到底，**没有分页条、没有区间文案**。不足 27 行照实渲染不补占位行。服务端接上后接口只需返回按 `sortType × period` 排好的前 30 条，超出不展示。
> 变更记录：v1 初版按稿做了 10 条/页三页分页，首页区间文案 `4–13 of 30` 与大众认知冲突（读作"13 个一页"），2026-09-29 CPO 裁定去掉分页。

### 2.5 ② Your Ranking
桌面 1232×88 横条 / 移动 358 卡，**恒显**，三态：
- **已排名**：副行 `My ranking · #N · M trades`；三格 PNL / ROI / Volume 各自按自身指标全量重排取名次（三个名次不相等是正常的）。
- **已登录未排名**：副行 `My ranking · Unranked · 0 trades`；名次位用 em dash；数值为真实零值 `$0.00 / 0.00% / $0.00`。
- **未登录**：主文案 `Sign in to see your rank`，副行 `Ranked by PNL, ROI and volume across all traders.`，三格数值一律 em dash（游客没有真实零值），按钮 `Sign in`。

### 2.6 ① 浮动定位器
桌面 fixed 右下 344×56；移动 `left/right 16`、`bottom = var(--bottom-nav-h) + 12`（永不盖底导）。
**只回答「我第几、我多少」，不承载分享。**
- 出现：视口在头图 → 表格之间，且 ② 未进入视口。
- 淡出：② 任意部分进入视口 → 150ms（opacity + 下移 4px），反向滚回淡入。
- 点击（已排名）：滚到我那行 → 高亮 1.5s（榜单不分页，无需翻页）。
- 点击（未排名）：滚到 ②。
- 未登录：整条变 `See where you rank` + `Sign in`。

### 2.7 分享弹窗与分享卡
桌面 384 居中浮层（底 `#14161A`、描边 `#1C1F26`、圆角 16、padding 20）；**移动端走 MobileDrawer**，不是居中弹窗（`DESIGN.md` §5 Mobile-zero-Dialog）。
四渠道 2×2 各 167×46（Save / Copy Link / X / Telegram）+ 主按钮 `More Options`。
分享卡 342×345 受 `DESIGN.md` §Addendum 2026-09-07「Lite 分享海报」LOCKED 约束：艺术底由设计导出且压暗层已烘进像素（**禁止用 CSS 渐变复刻**）、正文 `system-ui` + 数字 `Courier New`（**禁网络字体**，导出走 `skipFonts: true`）、盈利色 volt、OMENX 字标等比 11 高（按卡宽占比折算，原"固定 18"作废）。
**名次必须带榜别与周期（CPO 2026-09-29 补，稿未画）**：同一个人在 PNL / ROI / Volume 三个榜 × 四个时间范围上各有名次，海报只印 `#13` 无法说明是哪个榜。胶囊改为一颗说清的 `#N · <周期短码> <榜>`，如 `#13 · 7D PNL`（周期 Daily→1D / 7 Days→7D / 30 Days→30D / 180 Days→180D，榜名 PNL / ROI / Volume）；**成交笔数从卡上去掉**，胶囊下不再有第二行；三格里被排名的那一格加 1px 同色内描边。分享文案同步：`🏆 #13 · 7D PNL on the OMENX leaderboard — $… PnL, …% ROI.`。榜别与周期取自打开弹窗时筛选行的当前选择。

## 3. 色值口径（容易踩的一条）

金额位一律走 MONEY 轴 token：`--trading-green` = `74 100% 65%` = **`#CFFF4A`**，`--trading-red` = **`#FF5C5C`**。
**设计稿上的 `#D5FF4D` 不是 token**——它和 `#CFFF4A` 肉眼几乎分不出，但全站只有 3 处用过。实现时一律用 token，不要照抄稿上的值。

## 4. 演示值 / 等后端

当前榜单数据是前端常量（30 人 mock），**不是接口**。接真时需要：
- 榜单按 `sortType` × `period` 的服务端排序并只返回前 30（当前是前端全量排序 + 前端截取）；
- 当前用户的三指标名次（当前是前端对同一份 mock 排三次得到）；
- `trades` / `rankChange` 字段的真实来源。
