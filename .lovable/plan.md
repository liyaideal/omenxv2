# 移动端 logo-only 头部：改成有开场感的品牌栏

## 现在为什么“小气”
一级页（/events、/rewards、/wallet 等）的移动头部只放了一个 `h-5` 的小 logo + Mainnet 徽标，右侧塞的是一个纯占位的空方块，容器 `py-2`（总高约 40px），底下还压着一条实心分割线。结果是：一条又矮又满的横条，右半边空着却又被硬线切断，和下面 clamp(28–40px) 的大标题完全不在一个气场上。

## 改法（仅这一种状态：有 logo、无返回键、无标题、无右侧动作）

1. 长高、放大
   - 头部内容区高度提到约 56px（`py-2` → 更充裕的纵向留白），logo 从 `md`(h-5) 提到 `lg`(h-6)，Mainnet 徽标随之走 `md` 尺寸。
   - 去掉右侧那个纯占位的空 `w-9` 方块，让 logo 在左侧自然呼吸，右侧留白是有意的空，而不是被占位撑出来的空。

2. 分割线改成滚动才出现
   - 顶部静止时头部无 border、与页面同底色，视觉上和下面的大标题连成一个开场。
   - 页面滚动超过阈值（约 8px）后再淡入 1px 细分割线（及轻微背景实底），保证内容穿过时仍有层级。过渡用短时长淡入，不做位移。

3. 只影响这一种状态
   - 带返回键、带标题、带右侧动作、带第二行 stats 的头部形态一律不变（尺寸、行高、图标全部照旧），避免交易页/详情页版式位移。

## Style Guide
- 在移动端 header 展示区补 logo-only 状态的两个态：顶部静止（无线）与滚动后（有线），与既有的 back/title/actions 形态并列。
- changelog 加 2026-08-17 条目：移动 logo-only 头部改为开场式品牌栏（加高、logo lg、滚动才显分割线）。

## 技术说明
- 涉及文件：`src/components/MobileHeader.tsx`（logo-only 分支的尺寸/占位/边框逻辑 + 一个 scrollY 监听）、Style Guide 的移动端 header 展示节。
- 不改 `Logo.tsx` 的尺寸表，只在这一处换 size；不动 MainnetBadge、BottomNav、任何页面内容与业务逻辑。
- 验收：typecheck + build；393px 视口看 /events 顶部静止无线、滚动后出线，且 /trade、/spot、详情页头部像素不动。
