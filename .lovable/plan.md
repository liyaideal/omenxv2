## Problem

Two things are wrong with the art currently generated by `generate-event-image`:

1. **Wrong shape.** The prompt locks "square 1:1, single character centred, generous margins". The card tile is a wide strip (`h-[130px]`, full card width — roughly 2.6:1 to 3.5:1), so `background-size: cover` crops the square hard and leaves only the mascot's head, with the margins eating the frame.
2. **No story.** The prompt forbids any background ("flat paper grey, nothing else"), so every image is a lone mascot on empty paper. The cards should read as small scenes.

## What changes

Only the art-direction layer and the generated assets. No card/layout code changes — the tile stays `h-[130px]` with `cover`.

### 1. Wide cinematic framing

- Prompt asks for **21:9 ultra-wide landscape**, not square.
- **Safe zones baked into the prompt**, derived from the real card:
  - Badges sit top-left → keep the left ~30% low-detail (environment, not the subject's face).
  - A bottom scrim (`rgba(10,11,13,0.85) → transparent 60%`) darkens the lower half → keep the storytelling detail in the upper two-thirds.
  - Mascot anchored centre-right, **full body visible**, not cropped at the frame edge.
- After generation, verify the returned pixel ratio; if the model returns near-square, centre-crop to 21:9 server-side before upload so the card never receives a square again.

### 2. Narrative scenes instead of a lone mascot

The copy model (`openai/gpt-5.6-sol`) currently returns a "prop + pose" clause. It will instead return a compact **scene brief**: subject action, one hero prop, and 2–3 supporting environment elements that tell the story.

Examples of the intended result:
- *Coinbase — will close higher today?* → lynx at a small desk, ticker board in paw, chin on the other paw, candle chart taped to the wall behind, coffee cup, scattered paper.
- *2026 F1 drivers' championship* → lynx in a race suit on a podium step lifting the trophy, checkered flag and a rear wing silhouette behind, confetti.

### 3. Palette discipline kept (the part that was working)

Unchanged and still enforced, so a full grid stays calm: warm paper ground `#F2F2F0`, black ink line, charcoal fur, tan `#B49A6A`, plus **exactly one** brand accent per image (Pulse Blue `#33D6FF`, or Volt Green `#CFFF4A` for bullish/winning events). Environment elements are drawn in the same ink/grey family — they add story, not colour. Still banned: headline text, logos, UI frames, humans, glow, rainbow palettes. Short ticker lettering on a prop stays allowed.

### 4. Regenerate everything

Re-run generation for all live events (~21) plus the two already generated, so no square leftovers remain in the list.

### 5. Docs and style guide

- `DESIGN.md` §Addendum 2026-07-31 rewritten: 21:9, safe zones, scene-with-environment rule.
- `.lovable/memory/design/event-art-direction.md` updated to match.
- `/style-guide → Core UI → Event cover art`: samples swapped for the new wide art, shown **inside a real 130px card tile with the scrim and badges** so the crop is judged the way users see it.
